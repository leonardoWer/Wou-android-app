## Описание проекта
Андроид приложение, в котором собран весь функционал для занятий спортом. От просмотр видео тренировок до создания своих тренировочных планов и тренировок.
Подробнее [изучать ТЗ](ТЗ.md)

## Навигация

- [ ] [В папке `Backend` ссылка на репозиторий с бэком приложения](Backend)
- [ ] [В файле `ТЗ` техническое задание проекта](ТЗ.md)

## Правила работы с проектом
1. Создать ветку, название которой соответствует нику разработчика
2. Все изменения коммитить максимально понятно
3. После работы над приложением пометить выполненные задачи [в таблице](https://github.com/users/leonardoWer/projects/3)
