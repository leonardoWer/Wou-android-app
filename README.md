## Описание проекта
Андроид приложение, в котором собран весь функционал для занятий спортом. От просмотр видео тренировок до создания своих тренировочных планов и тренировок.
Подробнее [изучать ТЗ](ТЗ.md)

- [ ] [В папке `Backend` ссылка на репозиторий с бэком приложения](Backend)
- [ ] [В файле `ТЗ` техническое задание проекта](ТЗ.md)

## Правила работы с проектом
1. Создать ветку, название которой соответствует нику разработчика
2. Все изменения коммитить максимально понятно
3. Не сливать изменения с главной веткой без одобрения `@leonardo_Wer` или другого ответственного лица

## План работы
1. Создать дизайн максимального количества страниц
2. Перености дизайн в AndroidStudio
3. Используя ChatGpt и иные источники информации реализовывать функционал отедльных частей кода
   > Подробнее в [файле `ТЗ`](ТЗ.md)
4. Разработать иконки, мелкие детали
5. Дорабатывать функционал, оптимизировать работу
6. Добавлять правки для улучшения работы приложения
